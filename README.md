# 📚 국어과 맞춤형 실시간 라이브 학습지 (Live Worksheet)

> 교사가 평소처럼 한글(HWP/PDF)로 만든 국어 학습지 콘텐츠를 바탕으로, 교실에서 학생들과 실시간으로 호흡하며 수업을 진행하는 인터랙티브 라이브 학습지 웹 플랫폼입니다.

🌐 **실시간 웹 체험 주소:** [https://yerang-k.github.io/live-worksheet/](https://yerang-k.github.io/live-worksheet/)

---

## ✨ 핵심 기능

### 1. 🔄 교사 주도 통제 & 학생 자율 이동 (하이브리드 Pacing)
- **강제 동기화 모드**: 교사가 특정 활동(1~5단계)을 클릭하면 모든 학생의 화면이 해당 단계로 즉시 강제 이동하여 수업 집중도를 극대화합니다.
- **자율 탐구 모드**: 교사가 스위치를 켜면 학생 화면에 `[이전 / 다음]` 네비게이션이 활성화되어 지문을 천천히 읽거나 개별 과제를 자유롭게 수행할 수 있습니다.

### 2. 🧩 국어 수업 맞춤형 5종 인터랙티브 블록
- **📖 지문 해설 블록**: 윤동주 <쉽게 씌어진 시> 등 본문 텍스트와 함께 어려운 어휘(육첩방, 천명, 침전 등) 마우스 오버 시 **국어사전 뜻풀이 툴팁** 제공.
- **💭 실시간 생각 적기 블록**: 화자의 마음에 공감하는 한 줄 서술 제출. 학생 화면에는 **익명 포스트잇 보드**로 공유되며, 친구들의 글에 **❤️ 하트(공감)**를 누를 수 있습니다.
- **☁️ 워드클라우드 블록**: 시를 읽고 떠오르는 핵심 시어/키워드를 입력하면 실시간 빈도에 따라 단어 크기가 커지는 시각화.
- **📊 실시간 가치 탐구 설문**: 찬반 논제나 선호도 선택 시 실시간 막대 비율 그래프가 차오르는 토의 지원.
- **⏱️ 실시간 OX/객관식 퀴즈**: 카운트다운 타이머와 함께 즉각적인 정답 여부 및 상세 해설 제공.

### 3. 🛡️ 심리적 안전감과 생활지도의 공존 (익명/실명 듀얼 뷰)
- **학생 및 전자칠판 화면**: 모두 **익명(또는 재미있는 별명)**으로 표기되어 친구들 눈치를 보지 않고 솔직하고 적극적인 의견 표출 가능.
- **교사 관리자 화면**: 학번과 실명(`10301 김철수`)이 명확하게 매핑되어 미제출자 파악, 생활지도 및 개별 피드백 가능.

### 4. 🔒 학생 개인정보 보호 (제3자 서버 저장 금지)
- 별도의 회원가입 없이 PIN 번호와 학번/이름만으로 5초 만에 노트북/기기 접속.
- 학생들의 응답 데이터는 외부 서버에 전송되거나 축적되지 않으며, 교사의 로컬 브라우저 세션(`BroadcastChannel`) 및 구글 워크스페이스 내에서만 안전하게 관리됩니다.

### 5. 📥 수업 후 데이터 수합 및 사후 관리
- **구글 시트(CSV) 내보내기**: 원클릭으로 학생별 생각 작성 내용, 퀴즈 점수 등이 담긴 엑셀/시트용 파일 다운로드 (생활기록부 세특 연계).
- **오늘의 수업 요약 리포트**: 워드클라우드 스냅샷, 설문 결과 비율, 베스트 공감 생각이 한 장에 정리된 **A4 인쇄/PDF 리포트 모달** 제공.

- **Frontend**: Pure HTML5, CSS3, Modern Vanilla JavaScript (무의존성, 초경량)
